# Тест к уроку 1 «Что такое БПЛА»

**Формат:** 15 вопросов, один вариант ответа, автоматическая проверка.
**Максимум:** 15 баллов (по 1 за вопрос). **Рекомендуемый результат:** от 12 баллов.

---

## Настройки Google Формы

Перед вопросами добавить:

1. **Включить режим теста.** Настройки → Тесты → «Сделать тестом».
   Там же: «Показывать оценку сразу после отправки», «Показывать незачтённые вопросы».
2. **Три обязательных поля** (тип «Текст, строка»):
   - Фамилия
   - Имя
   - Группа / класс
3. Для каждого вопроса ниже: тип **«Один из списка»**, отметить обязательным,
   в «Ответы» поставить 1 балл и выбрать правильный вариант.

## Вопросы

**1. Что означает слово «беспилотный» в термине БПЛА?**
- [ ] Полётом никто не управляет
- [x] На борту аппарата нет пилота
- [ ] Аппарат летает без двигателя
- [ ] Аппаратом управляет только компьютер

**2. Что из перечисленного НЕ входит в состав беспилотной авиационной системы?**
- [ ] Летательный аппарат
- [ ] Пульт управления или наземная станция
- [ ] Канал радиосвязи
- [x] Взлётно-посадочная полоса

**3. Чем современный БПЛА принципиально отличается от простой радиоуправляемой авиамодели?**
- [ ] Он больше по размеру
- [x] Между командами пилота и моторами работает электроника, которая сама удерживает аппарат в воздухе
- [ ] Он летает только по программе
- [ ] Он не использует радиосвязь

**4. Как называется беспилотник с четырьмя винтами?**
- [ ] Гексакоптер
- [ ] Октокоптер
- [x] Квадрокоптер
- [ ] Конвертоплан

**5. За счёт чего создаётся подъёмная сила у аппарата самолётного типа?**
- [ ] За счёт винтов, направленных вверх
- [x] За счёт крыла при движении вперёд
- [ ] За счёт лёгкого газа внутри корпуса
- [ ] За счёт хвостового винта

**6. Почему аппарат самолётного типа при той же батарее летает дольше мультикоптера?**
- [ ] У него мощнее мотор
- [ ] У него легче аккумулятор
- [x] Его в воздухе держит крыло, а мотор нужен только для движения вперёд
- [ ] Он летит на меньшей высоте

**7. Какой тип аппарата НЕ умеет неподвижно висеть в одной точке?**
- [ ] Мультикоптер
- [x] Самолётного типа
- [ ] Вертолётного типа
- [ ] Конвертоплан

**8. Что такое конвертоплан?**
- [ ] Мультикоптер с восемью винтами
- [ ] Беспилотник, управляемый только по программе
- [x] Аппарат с крылом и винтами вертикального взлёта, сочетающий свойства коптера и самолёта
- [ ] Аппарат, который запускается с катапульты

**9. Сколько винтов у гексакоптера?**
- [ ] Четыре
- [x] Шесть
- [ ] Восемь
- [ ] Один большой и один хвостовой

**10. Что такое FPV?**
- [ ] Отдельный тип беспилотника
- [x] Способ управления, при котором пилот видит картинку с камеры дрона
- [ ] Название полётного контроллера
- [ ] Вид аккумулятора

**11. Полёт выполняется по заранее заданным на карте точкам, оператор только наблюдает. Как называется такой уровень?**
- [ ] Дистанционное управление
- [x] Автоматический полёт
- [ ] Визуальный полёт
- [ ] Ручное управление

**12. От чего в первую очередь зависит, нужно ли регистрировать аппарат и где на нём можно летать?**
- [ ] От числа винтов
- [ ] От цвета корпуса
- [x] От взлётной массы аппарата
- [ ] От марки камеры

**13. Чем отличаются разведывательный и ударный беспилотники по назначению?**
- [ ] Разведывательный летает выше
- [x] Разведывательный ведёт наблюдение и передаёт изображение, ударный несёт вооружение для поражения целей
- [ ] Разведывательный больше по размеру
- [ ] Между ними нет разницы

**14. Два внешне одинаковых квадрокоптера называют съёмочным и инспекционным. Чем они отличаются?**
- [ ] Конструкцией рамы
- [ ] Количеством винтов
- [x] Полезной нагрузкой на борту
- [ ] Типом управления

**15. Нужно составить точную карту поля площадью 400 гектаров за один выезд. Какой тип аппарата подойдёт лучше?**
- [ ] Мультикоптер, потому что он умеет висеть на месте
- [x] Самолётного типа, потому что важны время полёта и дальность
- [ ] Вертолётного типа, потому что он несёт большой груз
- [ ] Нанодрон, потому что он компактный
