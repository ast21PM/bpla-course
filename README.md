# Внутреннее устройство БПЛА

Учебное пособие для тех, кто не разбирается в дронах совсем. За семь уроков разбирается, что такое беспилотник, из каких узлов он собран и за что отвечает каждый из них — от пропеллера до полётного контроллера.

**→ [Открыть пособие](https://ast21pm.github.io/bpla-course/)**

---

## Что это

Статический сайт на чистом HTML, CSS и JavaScript. Без сборки, без зависимостей, без фреймворков — достаточно открыть `index.html` в браузере.

| | |
|---|---|
| Уроков | 7 |
| Схем | 15 собственных SVG |
| Видео | 7 встроенных плееров |
| Тестов | 7 по 15 вопросов, автопроверка |

Каждый урок построен по одной схеме: **цель → конспект → разобранные примеры → вопросы с раскрывающимися ответами → видео → тест**.

## Тесты

Тесты собраны в Google Формах. В папке `tests/` лежат скрипты Google Apps Script, которыми они создавались, — они нужны, чтобы тесты можно было воспроизвести или поправить.

| Файл | Что делает |
|---|---|
| `create-test-urok1.gs` … `create-test-urok7.gs` | создают форму с 15 вопросами, правильными ответами и баллами |
| `fix-test-urok1.gs` | переставляет варианты, чтобы верные ответы не скапливались на одной позиции |
| `open-access.gs` | открывает доступ по ссылке ко всем формам курса |
| `urok1-test.md` | вопросы и ключ к уроку 1 в текстовом виде |

Скрипт для уроков 2–7 копирует уже настроенную форму первого теста — так переносятся настройки показа оценки, и их не приходится выставлять заново.

**Как запустить:** открыть [script.google.com](https://script.google.com), создать проект, вставить содержимое файла, выполнить нужную функцию. При первом запуске Google запросит доступ к Формам и Диску.

После создания формы её нужно **опубликовать** в интерфейсе Google Форм — иначе она будет требовать входа в аккаунт. Скриптом это не делается: в Apps Script нет метода, открывающего форму всем желающим.

## Источники

Тексты конспектов, схемы и вопросы тестов подготовлены автором пособия. Фотографии аппаратуры — из личного архива.

Видеоматериалы принадлежат их правообладателям и размещены встроенными плеерами. Полный список с ссылками на оригиналы — на странице [«Источники»](https://ast21pm.github.io/bpla-course/sources.html).

## Важно

Пособие теоретическое. Оно объясняет устройство аппаратов, но не является инструкцией по сборке, настройке или эксплуатации. Полёты беспилотников регулируются законом: перед любым практическим запуском нужно изучить действующие правила своей страны и требования к регистрации аппарата.
